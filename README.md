AEGIS ORBIT — an original orbital shield-defense arcade game in pure HTML/JS. Swing a shield arc around your planet with the mouse or arrow keys, block incoming rocks, chain combos up to ×8, charge the PULSE shockwave with golden orbs and repair with green cores through escalating 22-second waves. All art is drawn in code and all sound is synthesized with WebAudio; it plays fully offline from static files under game/.

## Run it

```sh
python3 -m http.server 8000 -d game
```
